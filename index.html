📖 À propos du jeu

Description

Un jeu de puzzle où vous devez trouver le bon chemin en sélectionnant une séquence de déplacements pour atteindre l'arrivée en évitant les obstacles.

Les 3 zones du jeu

  • Zone 1 - Damier 5x5 : Grille avec point de départ (D), point d'arrivée (A) et obstacles aléatoires
  • Zone 2 - Séquenceur : Affiche votre séquence de mouvements sélectionnée
  • Zone 3 - Sélection : Boutons de direction (↑ ↓ ← →) pour créer votre séquence

Comment jouer

  1. Observer la position de départ et d'arrivée
  2. Planifier votre chemin en évitant les obstacles
  3. Cliquer sur les flèches pour créer votre séquence
  4. Appuyer sur "Exécuter" pour tester
  5. Utiliser "Reset" si vous vous trompez

Fonctionnalités

  • ✅ Génération aléatoire de niveaux
  • ✅ Animation case par case des déplacements
  • ✅ Détection des collisions
  • ✅ Feedback visuel (rouge = erreur, vert = victoire)
  • ✅ Nouveau niveau automatique après chaque victoire
